# Кибербезопасность для btw player

Учебный сайт о приватности и кибербезопасности.

Как тебя разводят на данные, что прячется в ссылках и файлах, как защититься,
и Академия на 12 глав о кибербезопасности целиком.

Адрес: https://medved-btw.github.io/

## Как устроен

- Обычный статический сайт: HTML, CSS и JavaScript без фреймворков и без сервера.
- Ничего не собирает: нет счётчиков, cookies и чужих скриптов. Шрифты лежат в `assets/fonts`,
  поэтому страница не обращается к сторонним серверам.
- Политика безопасности контента (CSP) в каждой странице разрешает скрипты, стили, шрифты
  и картинки только с самого сайта.
- В браузере (localStorage) хранятся только отметки чек-листа, прочитанные главы
  и выбор «спокойного режима».

## Файлы

- `index.html` главная, остальные `*.html` разделы, `glava-01.html` ... `glava-12.html` главы Академии.
- `assets/fx.css` стили, `assets/fx.js` эффекты (сборка по прокрутке, ASCII, расшифровка текста),
  `assets/app.js` чек-лист, тест, Лаборатория, словарь.
- `404.html` страница для несуществующих адресов.
- `.nojekyll` говорит GitHub Pages отдавать файлы как есть.

## Шрифты

Unbounded, Inter и JetBrains Mono под лицензией SIL Open Font License 1.1,
тексты лицензий лежат рядом с файлами шрифтов в `assets/fonts`.

## Оговорки

Все банки, магазины и люди в примерах выдуманные. Адреса в зоне `.example` зарезервированы
для учебных примеров. Раздел про закон не является юридической консультацией.
